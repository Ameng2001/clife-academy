# 定位：教研工坊与幼师学坊怎么分工（2026-10-22）

两件产品，一个闭环。

| | 教研工坊 | 幼师学坊 |
|---|---|---|
| 是什么 | 专业的课程研究工具 | 教师发展平台 |
| 教师来做什么 | 研究一门课，把它做出来 | 学该学的，分享做过的 |
| 内容从哪来 | 教师输入一句话，管线起草，教师逐步确认 | PGC：按岗位与领域编好的路径与关；UGC：教师在工坊做出来、班里用过的课，和园里真实做过的事 |
| 产出 | 主题网络图、周计划、内容大纲、课程计划表、逐节教案、配套资源、观察评价量表，docx / xlsx | 积分、学时证明、证书；入库的专家案例与课程成果 |
| 判断权 | 教研主任 | 园长同意、审核人入库 |

## 闭环

```
幼师学坊 学（PGC 路径）────积分────▶ 教研工坊 做（起草 → 确认 → 用）
     ▲                                              │
     └──── 课程成果（UGC：改了什么、用过有效）◀──────┘
```

1. 教师在幼师学坊按岗位走关，记积分。积分是平台唯一的资产，也是工坊的工具使用额度（docs/POINTS-DESIGN.md：不是货币、不排行、不可转赠）。
2. 教师在教研工坊做一门课。工坊起草，教师改、用、确认。
3. 用过的课分享回幼师学坊，成为课程成果。必须写「在起草稿上改了什么」，工坊起草不算成果，用过并改过才算。入库记积分，别的教师标「用过，有效」。
4. 课程成果和专家案例一起，是下一轮 PGC 的素材：名师讲堂讲它、合集收它、研讨关拿它出题。

## 幼师学坊的两个面

**PGC 面：教师发展平台。** 16 条路径 105 关，按岗位（保健医、班级教师、保育员、信息接口人、园长）、领域（观察、沟通、计划、环境、游戏、反思）、阶段（入职、骨干、管理）、区县管理员编，另有一条「用教研工坊做课」（目标怎么填才过、周计划选模板、教案先改三处、用过再分享）。每关讲、看、做、测，做是在平台上真做一次。这部分由运营方和专家编，有署名与审定。

**UGC 面：教研工坊的社区。** 两种东西：
- 专家案例：一件事怎么做。教师实名投，园长同意，审核人入库，标「可直接用 / 需改编 / 只看思路」，有改编来源链、轻形态、合集。
- 课程成果：一门课怎么来的。从工坊分享过来，带管线类型、年龄班、周数、五大领域、简介、改了什么、文件外链、工坊地址。流程同案例。

两种都实名、不显示人数、不排名、评作品不评人。

## 工坊怎么接

工坊侧加一个按钮「分享到幼师学坊」，用教师在学坊「设置 → 接口令牌」里建的投稿令牌调 `POST /api/works`，契约见 docs/WORKSHOP-SHARE.md。不搬引擎，不开新账号，不同步文件（只带下载外链）。

## 两个面在导航上怎么分

一级导航 首页 / 学习路径 / 精品微课 / 名师讲堂 / 教研共同体：左四项是学（PGC），最右一项是分享（UGC）。教研共同体页（/community）收专家案例、课程成果、合集、园所分享日、名师工作室，落地页做成内容社区的样子（夜 53，参照懂了鸭首页）：tab 最新 / 本园 / 本共同体 / 合集 / 按领域，一张「本期」大卡加「动动手」四个入口，下面是带封面的作品卡网格，可按类型、领域筛，可搜。不显示浏览与点赞数，没有「关注」。小程序同样五个 tab，共同体顶替了体检的位置。

## 不做的

- 不把工坊的生成界面嵌进学坊。学坊只收结果。
- 不在学坊展示工坊的课程评分、审核次数这类数字。
- 不自动把工坊里每门课都推到学坊。教师自己点「分享」，而且得先用过、改过。
- 不给课程成果做点赞、下载次数墙。
