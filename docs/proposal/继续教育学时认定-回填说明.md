# 一、事项

学前大课堂已能为每位教师出具继续教育学时证明。证明的计时口径与版式均为平台的可配置项，不需改程序。请局里对下列两张表逐项确认或改写，运营方在管理端一次填入，当日生效。

平台只记录教师本人的学习行为：通过的关卡、通过点评的实践作品、研讨作答、认证答辩、研修项目。不记录幼儿信息，不记录在线时长，证明上不出现测验分数。

# 二、计时口径

下表「平台默认」为现行取值；请在「市里口径」一栏填写确认值，与默认一致的写「同」。

| 项目 | 平台默认 | 说明 | 市里口径 |
|----------|------------|------------------------|----------|
| 学时折算 | 每 45 分钟折 1 学时 | 可改为 40、50、60 分钟等 | |
| 工具关 | 按关卡标定时长计 | 每关 3 至 8 分钟，课程包内标定 | |
| 实践关 | 关卡时长另加 60 分钟 | 作品通过点评方计，退回修改不计 | |
| 研讨关 | 关卡时长另加 30 分钟 | 提交作答即计 | |
| 骨干教师认证 | 答辩通过加 240 分钟 | 一次认证计一次 | |
| 研修项目 | 按期次核定学时计 | 寒暑假研修、园长研修等，完成方计 | |
| 园长大讲堂 | 不计 | 线上无到场记录；若市里认可预约且开播即计，可改为计 | |
| 取整 | 按 0.5 学时向下取整 | 可改为 0.25 或 1 | |
| 统计区间 | 学年，9 月 1 日至次年 8 月 31 日 | 亦可按自然年或任意区间出具 | |
| 年度上限 | 不设 | 若市里对线上学时设年度上限，请明示数值 | |

# 三、证明格式

| 项目 | 平台默认 | 市里口径 |
|----------|--------------------------|----------|
| 证明标题 | 继续教育学时证明 | |
| 出具单位 | 本地运营方（待确认） | |
| 落款与签章 | 无落款人；电子版不盖章 | 请明示出具单位名称、落款人及是否需加盖公章 |
| 编号规则 | XS－年份－五位流水号，如 XS-2026-00012 | 固定格式，不建议改 |
| 核验方式 | 凭编号在平台「学时证明」页核验，或由系统接口核验；核验结果姓名脱敏 | |
| 证明正文 | 兹证明某某（某某幼儿园）于某日至某日期间，在学前大课堂完成以下学习，合计若干分钟，按每 45 分钟折 1 学时、0.5 学时向下取整，计若干学时；下列学习项目、次数、分钟明细表 | |
| 背面说明 | 本证明所列学时按平台学习记录计算，计时规则见背面；证明编号可在平台核验 | 请改写或补充 |
| 纸质件 | 教师自行打印或存为 PDF | 如需统一纸质件，请明示由谁打印盖章 |

# 四、生效与存档

确认后的口径只影响此后出具的证明。每份证明出具时保存当时的口径快照，日后口径调整，已出具的证明不变、仍可核验。

建议于本学期内确认，以便春季学期起教师按市里口径出具证明。确认表可直接在本表上批注后回传运营方。
