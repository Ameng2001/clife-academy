# 教研工坊 → 幼师学坊：分享作品的功能设计（2026-10-22）

参照懂了鸭「发布作品 / 从外部 Agent 导入」那一章：作品在工具里做完，发布时系统替你生成题目与描述、适配三端，发布前只问两件事（允许下载、允许改编）；外部 Agent 的作品靠一枚个人令牌加一份创作 Skill 投进来，投进来先落成草稿，作者点进去手动发表；看到喜欢的作品点「改编」就能二创。

幼师学坊照这个形态做，但有三处不照搬：**「改了什么」不能自动生成**（工坊起草不算成果，用过并改过才算，这一栏是「人」的部分）；**不自动发表**（投进来仍走园长同意、审核人入库）；**不显示下载次数**（文件只带外链，学坊不存文件）。

## 一、三条路进来

| 路 | 谁用 | 入口 | 到学坊后 |
|---|---|---|---|
| **A 工坊内置按钮** | 用工坊做课的教师（主流） | 工坊课程工作台「交付」页右上角「分享到幼师学坊」 | 直接成一条待同意的课程成果（`consent` / 园长账号 `pending`） |
| **B 外部 Agent 导入** | 用 Claude、WorkBuddy 等 Agent 整理课程的教师 | 把一段指令和「幼师学坊分享 Skill」地址发给 Agent，Agent 读工坊导出的 docx / zip，整理成学坊要的格式，预览，确认后用令牌上传 | 落成**草稿**（`draft`），教师在学坊「课程成果 → 我交的」点进去补「改了什么」，再「交给园长」 |
| **C 手填** | 没用工坊、或工坊没联网的 | 学坊 `/works` 页「分享一门课」表单（已有） | 同 A |

三条路最后都是同一条记录、同一个流程、同一张卡。A 和 B 都用**投稿令牌**（`cla_`，学坊「设置 → 接口令牌 → 新建投稿令牌」，标签写「教研工坊」或 Agent 名），令牌只显示一次、最多 5 枚、可撤、不放大权限。

## 二、A 路：工坊内置按钮（工坊仓库做）

**按钮在哪**：课程工作台「交付」页，和「一键导出」并排。课程状态是「未完成 / 待提交」时按钮灰，鼠标放上去说「用过再分享」；「审核通过」或教师自己标过「已在班里用过」才亮。

**点了以后一张表，四栏**，前三栏工坊预填、教师可改，第四栏必须教师手打：

1. 标题、管线、年龄班、周数、领域：从信息采集带出来，不用改。
2. 简介（≥ 50 字）：预填课程的「主题由来」或项目导览第一段，教师可改。
3. 文件：勾选要带的产物（主题网络图、周计划、教案打包），工坊给每个勾选项一个**可长期访问的 https 下载地址**（学坊不存文件，失效由工坊负责）；默认只勾网络图和周计划，教案包太大默认不勾。
4. **在起草稿上改了什么**（至少一条，每条 ≤ 120 字）：空的提交按钮不亮。表下面给三个提示词：「幼儿应答」「材料」「环节数」，点一个就起一行「把 ___ 改成 ___，因为 ___」。工坊**不替教师生成这一栏**，也不从课程的修改记录里自动摘。

**发布前两个开关**（照懂了鸭）：

- 允许改编（默认开）：别的教师能点「改编这门课」，带来源链；关了只能看。
- 文件对谁可见（默认全平台）：全平台 / 本共同体 / 本园。简介、改了什么始终全平台可见，只有文件外链按这个收。

**令牌怎么到工坊**：工坊「个人设置 → 幼师学坊令牌」粘一次，存在工坊账号下。没粘过的教师点按钮，弹出一步说明：「到幼师学坊 设置 → 接口令牌 新建一枚投稿令牌，标签写教研工坊，粘到这里」，附学坊地址。工坊不替教师建学坊账号。

**提交**：`POST /api/works`（契约 docs/WORKSHOP-SHARE.md），带 `source: { courseId, url }` 与两个开关。成功后工坊在课程上记 `academyWorkId`，按钮变成「已分享 · 在幼师学坊里看」；教师在学坊退回后再改再交时带 `id`。

**署名仪式**（照懂了鸭绘本的那一步，可跳过）：提交成功的那一屏，问一句「给同行留一句话？」，≤ 80 字，存进 `message`，显示在学坊的卡片和详情上（「王老师：第二周换成本班儿歌以后，幼儿自己会唱着做了」）。不是评价、不是总结，是分享者对同行说的一句。

## 三、B 路：外部 Agent 导入（学坊仓库做）

照懂了鸭「给 Agent 一段指令 + 一个 Skill」。

**1. 一份 Skill**：学坊在 `GET /skill/share-work.md`（公开，不要登录）给一份 SKILL.md，Agent 读了就知道：

- 字段表与校验规则（同契约）；
- 从工坊导出物里怎么找信息：信息采集表 → 标题 / 年龄 / 周数 / 领域 / 目标；主题由来 → 简介；周计划 → weeks；教案 docx 的「活动反思」段 → **不许**当成「改了什么」；
- 先 `POST /api/works/draft` 落草稿，再把草稿地址（`/works?mine=1&id=…`）给教师，**由教师在学坊里补「改了什么」并提交**；Agent 不填这一栏，填了服务端也丢弃；
- 不带幼儿姓名与正脸，教案里预设的幼儿应答是剧本不算；
- 不带工坊评分、送审次数。

**2. 给教师的一段指令**（学坊「课程成果 → 分享一门课 → 用 Agent 整理」页上可复制）：

> 读 <SKILL 地址>，把我附上的这门课整理成幼师学坊的课程成果草稿，先给我看预览，我确认后用这枚令牌上传：cla_…。不要替我写「改了什么」。

**3. 草稿接口**：`POST /api/works/draft`，投稿令牌可调，字段同 `POST /api/works` 但 `changes` 可空、`summary` 可短于 50 字；状态 `draft`，只有本人看得到，不进园长队列，不给学分。教师在「我交的」看到草稿卡（灰底、标「草稿 · 经 <令牌标签> 导入」），点进去是和 C 路同一张表，预填好了，补完「改了什么」点「交给园长」才变 `consent`。七天没动的草稿自动删。

**4. 来源显示**：卡片和详情写「经「Claude」导入 · 王老师补改并提交」，`source.kind = 'token'`，`source.via` 是令牌标签。工坊地址有就显示「在教研工坊里打开这门课」。

## 四、改编（照懂了鸭「改编」按钮）

入库的课程成果详情上加「改编这门课」：

- 有工坊地址且工坊支持 `?from=<courseId>` 复制课程时，跳到工坊开一门新课（工坊仓库做）；
- 没有的，就在学坊开一张预填的分享表，`adaptedFrom: { workId }`，标题前加「改编」。改编版入库时原作者与改编者都署名，原成果记一次「用过，有效」（同专家案例的来源链）。

分享者关了「允许改编」就没有这个按钮。

## 五、学坊这边要加的（按先后）

| 项 | 改哪 | 量 |
|---|---|---|
| `message` 一句话、`allowAdapt`、`filesScope` 三个字段，卡片与详情显示 | `api/academy/works.js`、`views/Works.jsx`、`views/Community.jsx` 卡片 | 小 |
| `draft` 状态与 `POST /api/works/draft`，「我交的」草稿卡，七天清理 | `works.js`、`tokens.js` SUBMIT_ROUTES、`Works.jsx`、openapi、契约测试 | 中 |
| `GET /skill/share-work.md` 与「用 Agent 整理」页（指令可复制） | `server.js` 静态一条、`Works.jsx` | 小 |
| 课程成果的 `adaptedFrom` 来源链与「改编这门课」 | `works.js`、`Works.jsx` | 中 |
| 契约文档同步：WORKSHOP-SHARE.md 加 draft、message、两个开关 | docs | 小 |

工坊仓库那边：交付页按钮、四栏表、两个开关、令牌设置、署名一屏、`?from=` 复制课程。

## 六、不做的

- 不替教师生成「改了什么」，也不从工坊修改记录自动摘。
- 不自动发表：三条路都走园长同意、审核人入库。
- 不显示下载次数、浏览数、点赞；懂了鸭的「鸭蛋」互赠不做，积分是工具额度不流转。
- 不同步文件进学坊，只带外链。
- 不接受直接上传 HTML 之类的作品文件：课程成果的「作品」是文档与改动说明，不是可运行页面。
