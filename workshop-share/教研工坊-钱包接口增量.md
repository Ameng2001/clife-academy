# 教研工坊钱包页：幼师学坊侧接口增量（2026-10-22）

给做工坊线上版钱包页的同学。钱包页只有一个，在工坊；余额、分类、流水全部由学坊算好给过来，工坊只渲染，不自己算余额、不自己分类。学坊这边 14 个功能点的接口全部就绪，总账在学坊仓库 `docs/WALLET-TODO.md`，本文是把它们按接口整理成一份能直接照着写的东西。机器可读的接口定义在同目录 `wallet-openapi.yaml`。

## 一、前提

| 项 | 说明 |
|---|---|
| 密钥 | 工坊**服务端**带 `Authorization: Bearer <TOOLS_API_KEY>` 调下面六条接口。密钥由学坊运维生成（`openssl rand -hex 32`），两边各配一份。浏览器端不能拿密钥。 |
| uid | 统一登录后，传平台账号的 uid 即可，学坊按 `user.platform.uid` 找人；也认学坊自己的 `user.id`。应答里两个都给回（`uid`、`platformUid`）。 |
| 工具名 | `tool` 固定三个：`workshop` 教研工坊、`observe` 观察评价工具、`bagel` 贝果实验室。钱包页里显示名从握手应答的 `tools` 取。 |
| 两本账 | 教师自己的**积分**，和园长分给他的**园所额度**。工具扣减先扣额度再扣积分；额度只用在工具上，商城不能用。 |
| 不做的 | 充值、提现、转赠、排行、公开余额、与考核挂钩；签到、时长、浏览、点赞的奖励。接口里没有这些，页面也不要做。 |

## 二、六条接口

错误应答统一 `{ error, code }`。没配密钥 404 `off`，密钥不对 403 `tools-key`，uid 找不到人 404 `uid`。

### 1. 握手 `GET /api/tools/ping`

接上密钥后调一次，确认密钥、拿显示名和价表。不带 uid，不动账。

```json
{ "ok": true,
  "academy": { "name": "龙城幼师学坊", "short": "幼师学坊", "origin": "https://…" },
  "tools": { "workshop": "教研工坊", "observe": "观察评价工具", "bagel": "贝果实验室" },
  "groups": { "learn": "学与贡献", "interact": "互动", "tool": "工具扣减", "mall": "教学物料商城" },
  "uid": { "accepts": ["academy", "platform"], "note": "…" },
  "routes": { "balance": "GET /api/points/balance?uid=", "quote": "GET /api/points/quote", "spend": "POST /api/points/spend", "wallet": "GET /api/points/of?uid=" },
  "prices": { "theme": { "per": "week", "n": 30, "name": "主题式课程" }, "pbl": { "per": "week", "n": 40, "name": "项目式课程" }, "activity": { "per": "once", "n": 10, "name": "单节活动" } },
  "rules": { "…学与贡献的记分规则…" }, "quota": true }
```

### 2. 余额 `GET /api/points/balance?uid=`

轻量，给工坊顶栏或起草按钮旁边用。

```json
{ "uid": "…", "platformUid": "…", "name": "王老师", "orgName": "柳北区示例幼儿园", "points": 25, "quota": 60, "total": 85 }
```

### 3. 报价 `GET /api/points/quote?pipeline=&weeks=&adaptedFrom=&uid=`

起草确认前调，不动账。`pipeline` 是 `theme | pbl | activity`，`weeks` 1 到 20（单节活动不用传）。`adaptedFrom` 传学坊里那门入库成果的 id，就按 5 折（向上取整）。带 `uid` 就一并给余额和够不够。

```json
{ "pipeline": "theme", "weeks": 3, "full": 90, "n": 45,
  "adapted": { "id": "w_…", "title": "蜗牛为什么下雨天才出来", "byName": "赵园长" },
  "note": "改编自《蜗牛为什么下雨天才出来》 5 折 · 主题式 3 周",
  "prices": { "…同握手…" },
  "uid": "…", "points": 25, "quota": 60, "enough": true }
```

错误：`pipeline` 不认识 400 `pipeline`；`adaptedFrom` 那门成果没入库或不许改编 400 `adapt`。

### 4. 扣减 `POST /api/points/spend`

教师确认起草时调。幂等键是 `(tool, ref)`，`ref` 用工坊课程 id；同一键重复调答 `duplicate: true`，不再扣。

```json
{ "uid": "…", "tool": "workshop", "pipeline": "theme", "weeks": 3, "ref": "course-1522",
  "note": "可选，≤ 120 字", "adaptedFrom": "w_…" }
```

`pipeline + weeks` 与 `n`（正整数，工坊自己算价）二选一。应答：

```json
{ "ok": true, "duplicate": false, "points": 10, "quota": 30,
  "fromQuota": 30, "fromPoints": 15, "n": 45, "full": 90,
  "adapted": { "id": "…", "title": "…", "byName": "…" }, "note": "改编自《…》 5 折 · 主题式 3 周 · 可选备注" }
```

余额不够 **409** `insufficient`，带 `points` 与 `quota`，页面据此给两条路（见功能点 W13）。其他 400：`tool`、`n`、`ref`、`pipeline`、`adapt`。

### 5. 钱包整包 `GET /api/points/of?uid=&before=&limit=`

钱包页的主数据，一次拿齐。`limit` ≤ 500，不传就全给；翻页时 `before` 传上一页 `nextBefore`。`sections` 与 `total` 永远按全量算，只有 `history` 分页。

```json
{ "uid": "…", "platformUid": "…", "name": "王老师",
  "points": 25,
  "quota": { "left": 60, "used": 40, "orgName": "柳北区示例幼儿园" },
  "levelsPassed": 3,
  "sections": [
    { "key": "learn", "label": "学与贡献", "n": 55, "count": 4 },
    { "key": "interact", "label": "互动", "n": 0, "count": 0 },
    { "key": "tool", "label": "工具扣减", "n": -45, "count": 2 },
    { "key": "mall", "label": "教学物料商城", "n": -5, "count": 1 } ],
  "history": [
    { "kind": "spend", "sub": "quota", "group": "tool", "n": -40, "tool": "教研工坊", "note": "主题式 3 周", "at": 1792660000000 },
    { "kind": "spend", "group": "tool", "n": -5, "tool": "教研工坊", "note": "改编自《蜗牛…》 5 折 · 单节活动", "at": 1792650000000,
      "adaptedFrom": { "id": "w_…", "title": "蜗牛为什么下雨天才出来", "url": "https://…/#/works?id=w_…" } },
    { "kind": "earn", "group": "learn", "n": 10, "note": "过了 1 关", "at": 1792640000000 } ],
  "total": 7, "nextBefore": 1792640000000,
  "quotaLog": [
    { "kind": "alloc", "n": 60, "byName": "赵园长", "at": 1792630000000, "text": "赵园长 分了 60" },
    { "kind": "spend", "n": -40, "tool": "教研工坊", "at": 1792660000000, "text": "在教研工坊用了 40（主题式 3 周）" },
    { "kind": "recall", "n": -5, "byName": "赵园长", "at": 1792620000000, "text": "赵园长 收回没用的 5" } ],
  "rules": { "…" }, "tools": { "…" },
  "links": { "mall": "https://…/#/mall", "honors": "https://…/#/honors", "rules": "https://…/#/honors", "paths": "https://…/#/paths" },
  "mallHint": "换教学物料" }
```

字段要点：

- `history[].sub === 'quota'` 的几笔是从园所额度扣的，**不计入个人积分变动**，显示时标「园所额度」、数字淡色。
- `history[].group` 是四栏之一，筛选用；`history[].tool` 已是显示名。
- `quotaLog[]` 是教师视角的园所额度来龙去脉，`n` 正进负出，`text` 已是一句话。它不进 `history`，不算积分。
- 余额算法与学坊自己的页面同一份，工坊不要再算。

### 6. 来源核对 `GET /api/tools/work?id=&from=&uid=`

改编课开课前核对那门成果能不能改编，和钱包无直接关系，但 `adaptedFrom` 要从这里拿。答 `canAdapt`、`why`（`not-approved | not-allowed | course-mismatch`）、`label`「改编自《…》· 谁（园）」、`share.adaptedFrom`。成果不存在 404 `work`。

## 三、14 个功能点对应的字段

| # | 钱包页功能点 | 取什么 |
|---|---|---|
| W1 | 两行余额：「积分 N」「园所额度 N」 | `points`、`quota.left` |
| W2 | 园所额度一句：谁分的、来自哪个园、已用多少、只用在工具上、先扣它再扣积分 | `quota.orgName`、`quota.used` |
| W3 | 「换教学物料」入口，到学坊商城 | `links.mall`、`mallHint` |
| W4 | 没有额度、没分过时的空态一句（园所额度由园长分，到园长那里要） | `quota.left === 0 && quota.used === 0` |
| W5 | 四栏小计，各带笔数 | `sections[]` |
| W6 | 流水列表：日期 · 工具 · 备注 · ±n | `history[]` 的 `at`、`tool`、`note`、`n` |
| W7 | 从园所额度扣的几笔标「园所额度」，数字淡色 | `history[].sub === 'quota'` |
| W8 | 按四栏筛流水 | `history[].group` |
| W9 | 改编半价的几笔点开能到学坊那门成果 | `history[].adaptedFrom.url` |
| W10 | 分页或「加载更多」 | `?before=&limit=`，应答 `total`、`nextBefore` |
| W11 | 园所额度的来龙去脉 | `quotaLog[]` |
| W12 | 起草确认前的报价：原价、折后价、够不够、先扣额度多少再扣积分多少 | `GET /api/points/quote` 的 `full`、`n`、`enough`、`points`、`quota`；扣完的 `fromQuota`、`fromPoints` |
| W13 | 不够时的一句话与两条路：去学坊学几关、请园长分配园所额度 | `409 insufficient` 的 `points`、`quota`；`links.paths` |
| W14 | 价表展示：主题式 30 / 周、项目式 40 / 周、单节活动 10、改编 5 折 | 握手或报价应答的 `prices` |

## 四、一次起草的调用顺序

1. 教师选好管线与周数，若是改编课先 `GET /api/tools/work` 拿 `share.adaptedFrom`。
2. 确认页调 `GET /api/points/quote?…&uid=` 显示价、折扣、够不够。
3. 教师点确认，服务端 `POST /api/points/spend`，`ref` 用课程 id。`409` 就停下，显示 W13；`duplicate: true` 当成功。
4. 钱包页随时 `GET /api/points/of?uid=&limit=50`，加载更多带 `before`。

## 五、验收

学坊仓库里有 31 步的联调脚本，对着工坊实例跑，每步打印请求、应答与判定，最后一行 PASS / FAIL：

```
ACADEMY_URL=https://<学坊地址> TOOLS_API_KEY=… node scripts/workshop-spend-check.mjs --uid <教师 uid> [--work <入库成果 id>]
node scripts/workshop-spend-check.mjs --price theme 3 [--adapted]      # 只算价
```

脚本在学坊仓库 `scripts/workshop-spend-check.mjs`，根目录 `npm run check:spend`。扣掉的积分只在测试账号上。
